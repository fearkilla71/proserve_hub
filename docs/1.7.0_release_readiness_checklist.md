# ProServe Hub 1.7.0 Release Readiness Checklist

Use this checklist before promoting 1.7.0 beyond internal beta on Play Console
or TestFlight.

## Required Local Checks

Run from the repo root:

```bash
flutter analyze --no-fatal-infos
flutter test
cd functions && npm test
firebase emulators:exec --only firestore "cd rules_tests && npm test"
flutter build appbundle --release
```

Mac/iOS must also run:

```bash
flutter build ios --release --no-codesign
```

## Customer Smoke Test

- Start from landing and create/sign in to a customer account.
- Start a project from Home.
- Complete service/details/photo/contact/review steps.
- For supported instant-price services, confirm the AI price is saved and stays
  the same when returning without detail changes.
- Change a meaningful detail and confirm the price recalculates with a clear
  explanation.
- Request contractor quotes and invite recommended pros.
- Open Project tab and confirm the new project appears with the correct state.
- Review quote comparison, accept a quote, and confirm it routes into Job
  Command Center.
- In quote comparison, confirm every quote clearly shows price, ETA, contractor
  proof, scope, warranty, exclusions, deposit, and protected-payment guidance.
- After quote acceptance, confirm Job Command Center shows quote, escrow,
  invoice, and review state in one visible payment/closeout snapshot.
- Confirm escrow/payment labels are clear: pending, funded, failed, refunded,
  disputed, released.
- Complete chat, job completion, and review paths where test data allows.

## Contractor Smoke Test

- Sign in as Basic, Pro, and Enterprise contractors where possible.
- Confirm Home tool tiles match the active subscription tier.
- Confirm Enterprise Home emphasizes high-value business tools first: Profit &
  Loss, Crew Roster, Bid Analyzer, Quote Templates, Invoice, and Scheduling.
- Confirm lower-depth Enterprise tools such as Quality Inspector,
  Multi-Location, and Sub Marketplace remain available from Tools, but do not
  dominate the first Home grid.
- Confirm services selected in onboarding/profile match Browse Pros and lead
  matching.
- Browse leads, buy credits, unlock a lead, submit a quote, and open Job
  Command Center.
- Confirm payout setup status is consistent on Home, Tools, Plan, and payment
  screens.
- Tap Connect payouts and confirm success, resume, rate-limit, and failed states
  show user-friendly messages.
- Confirm invoices, saved estimates, render gallery, bid analyzer history, and
  empty states explain the next action.

## Admin Smoke Test

- Open Admin Operations.
- Review payment, escrow, dispute, moderation, verification, and lead-credit
  queues.
- Perform a safe test update on a dispute or moderation item.
- Confirm an action-history row appears with admin name/id, action, note,
  timestamp, and previous/new state.
- Confirm stuck payment or payout failures can be diagnosed without opening
  Firebase Console first.

## Offline And Recovery

- Toggle network offline during a draft/photo/message or supported write.
- Confirm the UI shows `Saved locally`, `Sync pending`, or `Sync failed`.
- Restore network and confirm pending writes retry.
- If retry fails, confirm the user can retry and does not lose the draft.

## Localization

- Test English and Spanish on Pixel 6 width.
- Confirm no clipped CTAs, chips, bottom nav labels, or quote/payment state
  labels.
- Check customer flow, contractor flow, payments, empty states, and admin
  operations for hardcoded English that blocks a Spanish user from finishing.

## Store Screenshot Mode

Screenshot/demo capture is available only in debug builds or builds compiled
with:

```bash
--dart-define=PROSERVE_DEMO_MODE=true
```

Use `/screenshot-demo` to jump to screenshot candidate screens for internal app
store capture. Do not expose this route in public production builds.
Use `docs/store_screenshot_capture_checklist.md` so Android and iOS capture the
same release story.

## Store Hold

Do not release publicly until Android and iOS have both pulled the same branch,
passed the checks above, and completed customer, contractor, and admin smoke
tests in both English and Spanish.
