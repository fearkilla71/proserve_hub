## 📸 Screenshot Order & Strategy

The 8 screenshots are ordered for maximum conversion:

| # | Name | Why This Order |
|---|------|---------------|
| 1 | **Dashboard** | First impression — shows the app is polished and feature-rich |
| 2 | **AI Estimates** | Unique differentiator — "AI" catches eyes in the store |
| 3 | **Find Contractors** | Core value prop — rated, verified pros |
| 4 | **Compare Bids** | Shows competitive advantage for the user's wallet |
| 5 | **Real-Time Chat** | Proves seamless communication |
| 6 | **Escrow Payments** | Trust & security — reduces objections |
| 7 | **Reviews & Reputation** | Social proof — multi-dimensional ratings |
| 8 | **Job Tracking** | Photo proof feed — unique, engaging feature |

**Pro tips:**
- Google Play shows only the **first 3** in the listing before the user has to scroll — put the strongest value props there.
- App Store shows **first 3** in Search, **first 1** on Browse — make #1 count.
- Use the same screenshots on both stores for brand consistency.

## 📊 A/B Testing Recommendations

Google Play has built-in **Store Listing Experiments**. Test these in order:

1. **Short description** — version A (current) vs. version B (alternatives above)
2. **Screenshot #1** — Dashboard vs. AI Estimate as the lead image
3. **Feature graphic** — current vs. a version with a customer testimonial
4. **App icon** — current vs. a variant with a house silhouette
